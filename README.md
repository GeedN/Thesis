## Chat, is this real?: Determining Statement Veracity Using LMs

### This code is submitted in partial completion of the CSAI Bachelor Thesis
The code in this repository belongs entirely to this account, excluding python modules available publically and the huggingface transformers code for each model, which can be found on the following links: [huggingface.co/Qwen/Qwen2.5-1.5B-Instruct][huggingface.co/Qwen/Qwen2.5-7B-Instruct][huggingface.co/Qwen/Qwen3-8B][huggingface.co/Qwen/Qwen3-0.6B]
